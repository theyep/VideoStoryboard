📢 이용 유의사항

스토리보드 생성기를 사용하실 때 아래 사항을 확인해 주세요.

  • 모든 데이터와 전체 스케치는 브라우저 캐시(localStorage)에 동적으로 저장됩니다.
  • 이미지 박스와 입력칸을 제외한 모든 여백을 마우스로 클릭한 채 드래그하면 상하좌우로 화면 이동이 가능합니다.
  • 축소(Zoom Out) 후에도 보여지는 빈 여백 전체에 자유롭게 스케치가 가능합니다.
  • 내보내기(PNG/JPG/PDF)를 하면 스케치된 영역만 자동으로 캡처되어 다운로드됩니다.
  • 스케치 작업 중 Ctrl + Z를 누르면 이전 단계로 되돌아갑니다.
